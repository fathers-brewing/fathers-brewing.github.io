# Fathers Brewing — website concept

A website concept for Fathers Brewing, designed and built by Maximilian Bedolla as a portfolio piece.
The official Fathers Brewing website is https://www.fathersbrewing.com.

Live at: https://fathers-brewing.github.io/

## Hosting
GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## Common edits
- Everything (copy, styles, scripts) lives in `index.html`.
- Photos: `img/photos/`; product and award art: `img/brand/`; merch: `img/merch/`; retailer logos: `img/retail/`; press thumbnails: `img/press/`.
- Links are plain links in `index.html`.
